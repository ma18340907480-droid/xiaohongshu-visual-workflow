# 小红书超级内容生产 Skill

> 为母婴类小红书账号打造的选题 + 文案 + 生图 + 排版 + 增长一体化 Agent 技能。
> 融合多个开源项目与创作者的公开方法论，结合母婴赛道实战标准二次改造。
> 使用者只需给出「做一篇小红书，主题是 XXX」，自动跑完 7 步交付成品。

**版本**：v1.0（2026-10）
**方法论来源**：写作结构与去 AI 味检查、视觉质检清单、选题与数据复盘、SEO 与热点方法、标题公式库等公开方法论（仅借鉴方法，不搬运任何具体内容）

---

## 最小输入

```
做一篇小红书，主题是 XXX
```

可选追加（不给就自动判断）：

- 角度：如「从省钱角度」「怼智商税」
- 素材：真实经历 / 数据
- 图数：默认 7 张，可指定 6~9

---

## 七步工作流（自动执行，不提问）

### 第一步：选题流量判断

**目标**：判断题材有没有流量潜力，不过就换角度，不硬写。

**方法**：

1. 痛点浓度：0-3 岁家长是否高频遇到？（是 = 高）
2. 情绪钩子：能否提炼出「怕 / 气 / 爽」其一？（能 = 高）
3. 涨粉潜力：精准新粉浓度——路过的人看了想关注吗？转粉钩子是什么？
4. 差异化：同赛道头部账号讲过吗？角度是否重复？
5. 时效性：是否蹭得上热点 / 季节？（24h 内热点优先）

**输出**：一句话判断（「可做，痛点是 XX，钩子是 XX」）+ 若否，直接换角度重判。

### 第二步：5 个标题 + 点击分析

**方法**（标题 6 公式 + 标题形状 + 家族混搭）：

- 6 公式：数字量化 / 痛点直击 / 悬念钩子 / 对比反差 / 人群点名 / 结果承诺
- 形状补充：`主角 + 动作 + 悬念后果`（如「月嫂偷偷告诉我：XX」）
- 铁律：5 个标题不许同模板，必须混搭；每个 ≤20 字；至少 2 个带提问 / 数字钩子
- 过滤：违禁词、极限词检查

**输出**：5 个标题 + 每个一句话点击分析 + 推荐 1 个（默认用推荐的）。

### 第三步：核心观点提炼

**方法**（亮点提取四问）：

1. 这篇最值得被转发的一句是什么？（答不出 = 没找到亮点，重想）
2. 这波砸了谁的场子？（智商税产品 / 错误观念 / 商家套路）
3. 谁赚到了？谁焦虑？
4. 普通宝妈看完应该意识到什么？

**传播四驱检查**：惊讶 / 站队 / 收藏 / 代入，至少命中 1 个，无驱动不写。

**输出**：一句话核心观点（这句话会出现在封面和金句页）。

### 第四步：正文写作

**结构**：反常识开头 → 冲突 / 故事 → 核心观点 → 举例 → 观点升华 → 自然引导评论

**写作红线**：

1. 禁诗歌排版（一句一段小短行），正文用段落式
2. 禁「不是…而是…」「不只是…更是…」「不可否认」「总而言之」
3. 禁正确但空洞的总结（如「行业迎来大洗牌」）
4. 禁 AI 口头禅：「值得注意的是」「那么问题来了」「总的来说」「在这个快速发展的时代」「随着社会不断发展」「我们应该」「不得不说」
5. 禁居高临下式科普（「我来翻译给你听」→ 换成「这对新手妈妈意味着啥」）
6. 禁硬转折（「但是 / 不过 / 而且」接近零）

**语言弹药库**（动词与口语词，母婴版）：

- 可用：砸场子 / 背刺 / 大冤种 / 智商税 / 割韭菜 / 劝退 / 闭眼入 / 踩雷
- 医疗红线：不编造数据、不替代医嘱、不点名批评无依据

**人设**（示例，可替换）：母婴产品研究员·敢说版——「我替你把功课做完了，难听的话我来说」

**信息密度**：每篇 2-4 个具体干货点（真实数据 / 具体产品名 / 可执行步骤），薄素材就写短不注水。

**去 AI 味诊断**（写完必跑）：

1. 前 80 字有真实场景吗？
2. 有约束取舍吗？（「XX 情况除外」）
3. 有万能句吗？→ 换具体动作
4. 太光滑吗？→ 加短打断 + 糙转折
5. 像真人说话吗？→ 加窄结果 + 局限性

### 第四步半：视觉栏目选择（先于封面方案，最高优先级）

**总逻辑：多视觉栏目体系，禁止固定模板化创作。**

旧的固定体系（米白底 + 手绘边框 + 插画 + 大标题 + 橙色重点字）重复率太高、视觉疲劳、像 AI 批量模板号，正式废止。每一篇先判断内容属性，再从 7 个视觉栏目里选最适合的表现形式，主动轮换：

1. **真实生活摄影感**：家庭、妈妈、宝宝、餐桌、卧室、推车等真实生活场景，像生活方式杂志（AI 生图按「手机实拍感」标准：自然皮肤纹理、不磨皮、生活杂物入镜；中文仍 PIL 排版）。
2. **高级杂志感**：大面积留白、摄影主体、精致排版、小标题，**不要边框**。
3. **极简信息图**：适合睡眠、辅食、发育、月龄对照等知识内容，用时间轴、数字、流程图表达（手绘资料卡降为本栏目的可选子风格，不再是全号默认）。
4. **情绪故事感**：一个真实育儿场景制造情绪（深夜哄睡、一个人吃饭、宝宝第一次叫妈妈），文字少但有冲击力。
5. **轻漫画叙事**：4~6 格连续画面，靠人物动作和对白讲故事，不是一张插画配一堆文字。
6. **生活抓拍感**：模拟手机随手拍、家庭记录、育儿日记，避免过度精致和 AI 感。
7. **创意视觉**：按选题设计独特构图——拼贴、局部特写、物品隐喻、摄影 + 文字等。

**核心规则（硬性）**：

- 连续两篇不得使用相同视觉结构（查台账 layout-history 的「视觉栏目」列）。
- 不要每篇都用米白色；不要每篇都用手绘插画；不要每篇都加边框；不要每篇都把标题放最上方；不要每篇都用「标题 + 插画 + 知识点」结构。
- 不要为了账号统一牺牲视觉变化；识别度靠内容气质（年轻妈妈真实记录 + 有用知识 + 轻松有梗），不靠模板。
- 禁止明显 AI 绘画质感、塑料感、过度磨皮、过度完美的家庭场景；视觉要有真实生活气息，同时保持审美。
- 判断顺序永远是「这篇内容最适合什么视觉」>「账号之前用了什么」。

**选栏目流程**：①判断内容属性（知识型 / 情绪型 / 故事型 / 好物型 / 记录型）→ ②从 7 栏目选最贴合的一个（篇内可混搭 1 个副栏目）→ ③查台账确认与上一篇栏目不同 → ④再进入封面与多图设计。**完工后把本篇视觉栏目追加进台账。**

**仍然有效的规则**：封面 3 秒看懂解决什么问题；中文一律 PIL 精准排版、AI 只出无字底图；禁用明显 AI 感的精致大场景插画；不照搬任何博主的具体内容、文字、插画、版式。

### 第五步：封面方案

先定类型（4 选 1）：

- A. 痛点大字报：纯文字排版，大字 + 高对比（适合观点 / 避坑类）
- B. 对比冲突：左右 / 上下对比（适合「贵 vs 便宜」「对 vs 错」）
- C. 场景 + 产品：真人使用场景（适合好物 / 测评类）
- D. 清单预告：标题 + 3-4 个要点预览（适合干货 / 攻略类）

**封面 9 要素**（每次说明）：图片主体 / 构图 / 人物位置 / 背景 / 光影 / 色彩 / 封面大字 / 字体感觉 / 视觉冲突点

**铁律**：

- 封面大字 ≤15 字，禁标题党
- 高明度底色（缩略图自查：深色底 + 小字 = 点击率暴跌）
- AI 只出无字底图，中文一律 PIL 排版

### 第六步：AI 生图 Prompt

**模板**：

```
[主体] + [场景] + [构图] + [镜头] + [光影] + [色彩] + [材质] + [氛围] + [画面比例] + [风格]
+ 固定后缀：no text, no words, no typography, no watermark
+ 色调与风格：按第四步半选定的视觉栏目决定，不再全号锁定一套。
  摄影感 / 抓拍感栏目 → 真实生活场景、自然光、手机实拍质感、natural skin texture、不磨皮、生活杂物入镜；
  杂志感栏目 → 大面积留白、单一摄影主体；
  仅③极简信息图栏目可用手绘子风格（简洁小插图 / 图标化元素、naive doodle）；
  轻漫画栏目 → 简单线条分镜人物、动作和对白驱动
+ 通用禁令：严禁精致 AI 大场景插画、严禁塑料感 / 过度磨皮 / 过度完美的家庭场景；页面文字一律 PIL 排版
```

**人物铁律**：涂鸦人物越简单越好——不要精致五官、大眼睛、对称脸、光滑皮肤；真人感场景图才用自然皮肤纹理标准。

**视觉质检**（出图后必查）：

- [ ] 无居中主视觉式构图？
- [ ] 无三等分卡片模板感？
- [ ] 无纯黑 #000？
- [ ] 强调色 ≤1 个？
- [ ] 无 AI 紫蓝渐变？
- [ ] 无假数据？
- [ ] 阴影染色（非纯灰）？

### 第七步：多图规划（6~9 张）

默认 7 张，结构：

| 页码 | 功能 | 内容 |
|------|------|------|
| P1 | 封面 | 大字 + 钩子，高点击率 |
| P2 | 问题 / 冲突 | 摆出痛点，引发共鸣 |
| P3-P5 | 核心内容 | 每页 1 个观点，可执行 |
| P6 | 总结 | 清单 / 对照表，值得收藏 |
| P7 | 观点 / 金句 + 引导 | 金句 + 自然引导评论 + 关注 |

**每页交付**：完整文案 + 生图 Prompt（无字底图）+ PIL 排版说明。

**先重写再排版**：不许把长文硬切成图，每页文案按「1 页 1 观点」重写。

**PIL 执行标准**：

- 900×1200 竖版 3:4；字体按栏目选：杂志 / 极简风用思源黑体，手写感栏目可用站酷快乐体（标题）+ 马善政体（正文），见仓库 `fonts/README.md`
- 每页一核心观点、≤3 个信息点，缩略图（300px 宽）下核心结论必须可读
- 完工后更新台账

## 长期迭代

**数据复盘**：

- 72h 三段观察：2h 冷启动 / 24h 推荐池 / 72h 长尾
- 核心指标：阅读 : 点赞（10:1 爆款线）+ 转粉率（新增关注 / 阅读）
- 归因：涨粉归因 > 互动归因（目标是涨粉）

**涨粉二分诊断**：涨粉数 = 阅读量 × 转粉率。数据差先分清是哪边的问题——没人点是选题 / 封面 / 标题的事，点了不关注是内容和人设的事，两边药方完全不同。

---

## 禁区

- 不写传统营销号（标题党 / 贩卖焦虑无底线 / 假测评）
- 不堆空洞鸡汤
- 不为了迎合平台把内容写假
- 医疗内容严谨，不编造数据
- 禁「评论区聊聊 / 说说」类生硬互动话术

## 补充：长期生产标准「真实感优先」（2026-10-23 定版，最高优先级）

全文见 `docs/production-standard.md`。执行要点：

- **总纲**：不要生成一张 AI 母婴海报，要生成一篇真实妈妈会收藏、转发、评论的小红书笔记。真实感 > 设计感，收藏价值 > 单纯好看，真实产品 > 虚构产品，妈妈语言 > AI 话术。
- **产品真实性**：只用真实存在的品牌产品；禁虚构品牌/包装/Logo；创作者给真实产品图时优先用原图（裁切/标注/合集/对比），不重新生成类似产品。
- **视觉轮换 A–O 15 型**：超市实拍/家庭桌面清单/宝宝使用场景/产品合集/手写攻略/产品对比/购物车价格/时间线/经验总结/知识卡片/照片拼贴/一张图讲清楚/聊天记录便签/生活照片＋局部标注/真实产品图＋手写箭头。与栏目、风格、版式各层并行查台账避重；同篇内部统一；禁每张图都是满设计海报。
- **图数 6-10 张**：封面→场景/问题→知识点→真实产品→使用场景→避坑/对比→购买建议→收藏清单；每篇至少 1-2 张值得截图保存的信息图。
- **不虚构个人经历**：没有真实经历时禁写「我亲测/用了三个月/我家一直在用」，改用「很多新手妈妈会纠结/这个阶段通常可以重点关注」。
- **健康内容谨慎**：禁功效断言（治疗湿疹/提高免疫力/防止过敏等），用「可以重点看看/不同宝宝情况不同」。
- **发布前 11 项自检**：真实性/AI 感/产品/信息/收藏/场景/文案/视觉差异/重复/标题/商业感，任一明显不合格就重做。
