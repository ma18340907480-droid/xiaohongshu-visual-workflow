# 示例：《带娃最累的不是身体》（高收藏知识卡版）

与情绪共鸣示例（mama-mental-load）**同一篇文章的第二种做法**：不走情绪叙事，改走「一眼看懂 + 信息密度高 + 方便收藏」的知识卡路线，7 页，1080×1440 竖版（3:4）。系列名：**妈妈安心指南 · 01**。

借鉴对象是爆款母婴卡片笔记的**内容组织方式与收藏逻辑**（封面点题 → 结论先行 → 模块拆解 → 误区对照 → Checklist 收尾），不复制任何具体文案、图片与版式。

## 栏目判断

内容属性：情绪型原文，但目标改为收藏与对着看。主栏目：**③极简信息图（高收藏知识卡子风格）**，混搭摄影页（封面、陪伴页、收尾照片带）给信息页留呼吸口。

## 视觉系统（统一但不复制模板）

- 奶油底（#FBF5EA）+ 白色圆角卡 + 浅米色投影；暖棕正文（#4A3826），浅橙（#DE8234 系）做强调
- 标题站酷快乐体（亲切），正文思源黑体；中文全部 PIL 排版，AI 只出无文字照片
- 统一的是字体、色彩、圆角、系列标（左上「妈妈安心指南 · 01」）；变化的是版式：照片封面 / 序号结论卡 / 单字图标清单 / 深色搜索页 / 照片渐显清单 / ❌✅对照卡 / Checklist

## 逐页结构

| 页 | 内容 | 版式 |
|---|---|---|
| P1 | 封面「带娃最累的，不是身体」 | 实拍感照片满幅 + 双色大标题 + 底部白条副标题 |
| P2 | 核心结论「先记住这几句」 | 4 张序号白卡 |
| P3 | 脑内待办清单（吃/睡/穿/医/比） | 单字圆图标 + 双行说明 |
| P4 | 深夜搜索清单 + 安心结论 | 全套唯一的深色页：搜索框圆条 + 底部白卡 |
| P5 | 孩子真正需要的 4 件事 | 喂饭照片 + 底部渐显 + 橙点清单 |
| P6 | 误区对照（焦虑念头 → 安心想法） | ❌/✅ 双行对照卡（×、✓ 为 PIL 线条绘制，不用 emoji） |
| P7 | 收藏 Checklist + 系列预告 | 顶部背影照片带 + 待勾选卡 + 收藏引导条 |

## 内容口径

- 只拆解原文已有内容，不新增原文没有的知识点、不编造数据
- 焦虑词只以「妈妈的念头」形式出现在 ❌ 行并被 ✅ 行纠正；正文不用「必须/一定/落后」等绝对化表达，发育话题一律强调个体节奏差异
