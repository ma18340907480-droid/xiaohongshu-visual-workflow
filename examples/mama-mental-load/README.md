# 示例：《生完孩子才发现，真正累的不是带娃》

一篇「情绪共鸣型」内容的完整成品，6 页，1080×1440 竖版（3:4）。与睡眠时间表示例的知识型路线完全不同：这一篇不讲知识点，讲的是「当妈以后脑子永远停不下来」的共鸣与安慰。

## 栏目判断

内容属性：情绪型（真实妈妈视角 + 强共鸣 + 轻度焦虑 + 情绪价值），目标是评论和转粉，不是收藏数据表。
主栏目：**④情绪故事感**；副栏目：**①真实生活摄影感**。全篇摄影打底，无边框、无信息卡、无手绘元素——和上一篇③极简信息图形成最大反差（硬规则：连续两篇不得同结构）。

## 视觉语言

- 底图全部为 AI 生成的「实拍感」照片：普通年轻妈妈 + 真实宝宝、自然皮肤质感、不过度磨皮、无网红脸、无广告海报感
- 色调：奶油白、米色、浅木色、柔和自然光，少量低饱和色
- 中文一律由 PIL 精准排版（AI 生图不写字）：大标题思源宋体 Bold、手写感小字用马善政体、次级信息思源宋体 Regular
- 暖棕（#4A3826）为浅底文字色，暖白（#FFF8EC）为深底文字色

## 逐页结构（每页版式都不同）

| 页 | 画面 | 版式 |
|---|---|---|
| P1 | 夜晚客厅，宝宝睡着，妈妈在沙发上刷手机 | 上方暖墙留白 + 宋体大标题两行 + 手写小字点题 |
| P2 | 宝宝开心玩木积木，妈妈托腮担忧 | 杂志式散排：大问句置顶，5 个焦虑小念头以不同角度零散落在左墙留白上 |
| P3 | 深夜床上，宝宝睡着，妈妈被手机光照亮 | 顶部白字大标题 + 手写体「搜索词」浮在暗部，营造越搜越焦虑 |
| P4 | 阳光里妈妈抱着宝宝 | 底部地板留白大字（浅色渐变罩提亮底） |
| P5 | 妈妈给宝宝喂饭 | 大留白：上方只放 4 行小字，呼吸感优先 |
| P6 | 母子牵手背影走向阳光 | 底部深色渐变罩 + 白字双行收尾 + 手写小字互动 |

## 内容口径

- 焦虑只写到「共鸣」为止，全篇落点是安慰：孩子不需要 100 分的妈妈，妈妈也不用每天考试
- 不编造任何数据、不给医疗建议；情绪型内容不借焦虑卖货

## 本篇沉淀的制作规则（已同步进 docs/visual-columns.md 迭代记录）

1. 情绪型选题优先全摄影路线，摄影底图要在提示词里预留排字区（暖墙、暗部、地板、画面上方留白）
2. 底图验收必查整幅画面：出现顶部整幅黑边等坏区直接重生，不靠裁图硬救
3. 旋转散排的小字必须在画布上居中绘制再旋转定位，否则文字会飞出画面
4. 渐变罩用 1px 竖条拉伸生成，逐列步进绘制会出现竖条纹
