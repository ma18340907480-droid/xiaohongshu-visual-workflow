# 示例：《宝宝睡得越久越好吗？0-12 个月睡眠时间表》

一篇「时间表 / 对照型收藏内容」的完整成品，6 页，900×1200 竖版。

## 栏目判断

内容属性：知识型（月龄对照 + 睡眠参考范围），收藏价值优先。
主栏目：**③极简信息图（现代杂志版）**；副栏目：封面混搭 **①真实生活摄影感**，第 5 页混搭 **⑥生活抓拍感**，给信息页之间留一个真实生活的呼吸口。

## 视觉语言

- 冷白底（#F8F9F9），无边框、无纸纹、无手绘元素
- 思源黑体（Noto Sans CJK）全篇排版，标题 Bold、正文 Regular
- 唯一强调色：深青（#14665C）；墨色正文 + 灰色次级信息
- 细灰直线做分隔，大量留白，大数字

## 逐页结构

| 页 | 内容 | 结构 |
|---|---|---|
| P1 | 封面「宝宝每天到底睡多久？」 | 实拍感照片打底 + 底部浅色渐显 + 杂志式排字 |
| P2 | 0-12 个月睡眠变化总览 | 交替式时间轴：5 个月龄节点，大号时长数字 + 一句特点 |
| P3 | 0-3 个月 | 数字英雄区「14-17 小时」+ 编号短句 |
| P4 | 4-6 个月 | 白天 / 夜里左右对照，细线分栏，睡眠倒退提示 |
| P5 | 7-9 个月 | 夜拍抓拍照片 + 妈妈观察记录式三段文字 |
| P6 | 10-12 个月 | 极简清单 + 大字结论 + 互动条 |

## 内容口径

睡眠时长全部使用儿科通用的**参考范围**表达（0-3 月 14-17 小时、4-11 月 12-15 小时、1 岁 11-14 小时），全篇不出现「必须睡满」「睡不够会影响智力」这类绝对化、制造焦虑的判断，并明确标注「个体差异很大」。

## 复现

排版脚本：[`../../scripts/make_sleep_timetable.py`](../../scripts/make_sleep_timetable.py)（底图照片在 `assets/` 目录，由 AI 按实拍感标准生成、无文字，中文全部由脚本用 PIL 排版）。

```bash
pip install -r ../../scripts/requirements.txt
python3 ../../scripts/make_sleep_timetable.py
```
