# 字体说明

本仓库不打包字体文件，请自行下载后放入本目录（或使用系统已安装的同名字体）。

| 用途 | 字体 | 来源 |
|------|------|------|
| 杂志 / 极简风正文与标题 | 思源黑体 Noto Sans CJK | [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+CJK+SC) / 系统自带 |
| 手写感标题 | 站酷快乐体 ZCOOL KuaiLe | [Google Fonts](https://fonts.google.com/specimen/ZCOOL+KuaiLe) |
| 手写感正文 | 马善政体 Ma Shan Zheng | [Google Fonts](https://fonts.google.com/specimen/Ma+Shan+Zheng) |

以上字体均为开源字体（SIL Open Font License），可免费商用。

注意：Noto Sans CJK 的 `.ttc` 字体合集里包含多语言字形，用 PIL 打开时需指定 `index=2` 才是简体中文（SC）。
