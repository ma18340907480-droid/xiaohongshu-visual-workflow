# 多视觉栏目体系

## 为什么要废止固定模板

固定模板的问题不在第一篇，在第十篇。「米白底 + 手绘边框 + 插画 + 大标题 + 橙色重点字」这类组合，单独看每篇都合格，连起来看就是批量生产。读者刷到第三张同构图的图片时，不会点开，只会划走；更糟的是，账号会被贴上「AI 模板号」标签，再好的内容也先输一半信任。

所以新体系的总原则只有一条：**内容决定视觉，识别度靠气质不靠模板。**

账号气质锚点（以母婴号为例）：年轻妈妈的真实育儿记录 + 有用的育儿知识 + 轻松有梗的生活观察。每篇长得不一样，但气质是同一个人。

## 7 个视觉栏目

### 1. 真实生活摄影感

家庭、妈妈、宝宝、餐桌、卧室、推车等真实生活场景，像生活方式杂志。用 AI 生图时按「手机实拍感」标准下提示词：自然光、真实皮肤纹理（natural skin texture）、不磨皮、允许生活杂物入镜。适合好物实测、场景化经验分享。

### 2. 高级杂志感

大面积留白、单个摄影主体、精致排版、小标题。**不要边框。** 适合观点类、盘点类、想拉高账号质感的内容。

### 3. 极简信息图

适合睡眠、辅食、发育、月龄对照等知识内容，用时间轴、大数字、流程图、对照表表达。信息密度可以高，但层级必须清晰，重点数字放大、关键词用强调色标出。手绘资料卡是本栏目的一个可选子风格，不是全账号的默认脸。

### 4. 情绪故事感

用一个真实育儿场景制造情绪：深夜哄睡、一个人吃饭、宝宝第一次叫妈妈。文字少而准，一张图讲一个瞬间。适合共鸣型、涨粉型内容。

### 5. 轻漫画叙事

4~6 格连续画面，靠人物动作和对白推进故事，而不是「一张插画配一堆文字」。人物造型全篇保持一致，线条越简单越耐看。

### 6. 生活抓拍感

模拟手机随手拍、家庭记录、育儿日记。构图可以不完美，光线可以不均匀，要的就是「这是真生活」的感觉。避免过度精致和 AI 感。

### 7. 创意视觉

根据具体选题单独设计构图：拼贴、局部特写、物品隐喻、摄影 + 文字等。没有固定公式，唯一的要求是构图为内容服务，不为炫技。

## 硬规则

1. 连续两篇不得使用相同视觉结构（开工前查台账，完工后更新台账）。
2. 不要每篇都用米白色；不要每篇都用手绘插画；不要每篇都加边框；不要每篇都把标题放在最上方；不要每篇都用「标题 + 插画 + 知识点」结构。
3. 不要为了账号统一而牺牲视觉变化。
4. 禁止明显的 AI 绘画质感、塑料感、过度磨皮、过度完美的家庭场景。
5. 选栏目的判断顺序：内容最适合什么视觉 > 账号之前用什么。

## 选栏目流程

1. 判断内容属性：知识型 / 情绪型 / 故事型 / 好物型 / 记录型。
2. 从 7 个栏目中选最贴合的一个作为主栏目，篇内可混搭 1 个副栏目（如信息图主页 + 摄影感封面）。
3. 查台账（layout-history），确认与上一篇栏目不同；同题多解时选差异最大的。
4. 再进入封面与多图设计。
5. 完工后把本篇栏目追加进台账。
