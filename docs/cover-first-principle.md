# 封面优先原则（2026-10-24 钦定）

封面不是门牌，封面本身就是产品。

- 最值得收藏、最有信息密度、最能解决用户问题的内容放第 1 张；废止「纯标题封面 + 末页干货」结构。
- 第一张同时完成：点击吸引力 + 核心知识价值 + 收藏理由；直接露出核心 3–5 个知识点，视觉主体必须与主题直接相关（真实摄影/真实产品/真实场景）。
- 信息密度：核心结论 + 关键数字/清单 + 强视觉主体，手机屏可快速扫完，重点字足够大。
- 收藏钩子：先问「用户只能存一张，他最想存什么」，就放那个；封面可直接做成完整知识卡（清单/对照表/时间轴/避坑表）。
- 默认结构：P1 核心知识+标题 → P2 详细解释 → P3 第二组知识 → P4 第三组知识 → P5 场景/案例/对照 → P6 补充+行动建议（可按主题调整，非固定模板）。
- 验收：只看第一张会不会想保存？不会就重做。
