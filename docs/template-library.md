# 版式模板库 A–H（2026-10-23 定版）

开工先判断「这个主题最适合哪一种版式」，再设计图片。禁止套模板填内容，禁止为视觉牺牲信息密度。

| 模板 | 形态 | 适合内容 |
|---|---|---|
| A 知识长图卡片 | 一张图集中放多个实用知识点 | 判断表、对照汇总、随身手册类 |
| B 月龄对照表 | 表格/时间轴呈现月龄变化 | 0-12月发育、睡眠时长、辅食进程 |
| C 手绘知识海报 | 大标题+手绘宝宝插画+关键知识点 | 单点知识、认知类 |
| D 多页知识卡 | P1 吸引点击，后页逐步讲清 | 分层展开的主题 |
| E 清单型 | 备忘清单式排版 | 护理细节、用品清单 |
| F 生活场景型 | 真实家庭场景主视觉+少量知识 | 情绪共鸣、行为类 |
| G 杂志/手账感 | 设计感排版+清晰信息 | 经验总结、阶段复盘 |
| H 极简信息图 | 少插画多信息 | 数据型、流程型 |

轮换纪律：不定期交替、禁止固定循环、连续两篇不得同模板；底色/边框/插画/构图四要素不得篇篇相同；选模板查 layout-history 台账。

收藏感来源（源自账号主页截图样例的拆解，只学逻辑不抄版式）：一眼看懂主题、信息分区清楚、手作温度（米白奶油底+手写标题+手绘小插画+少量装饰）、截图脱离正文可独立使用、密度够但不挤。
