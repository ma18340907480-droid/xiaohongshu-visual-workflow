# 封面版式规则 V3（2026-10-24 钦定）

第一张永远优先九宫格 → 不合适六宫格 → 再不合适自由设计；第一张 = 最值得收藏的内容（与封面优先原则并行）。

- 每格有分工：一个关键词 / 一个知识点 / 一个实物；短标签如「衣服｜别囤太多」。
- 必须有视觉中心：中心格放核心标题+结论，周围格子是视觉证据。
- 素材：真实产品/官方图/电商图/局部特写优先；局部肢体 > 完整真人全景（手拿用品、宝宝脚+鞋、车轮+折叠结构）。
- 轮换 A–H：标准九宫格/六宫格/不规则九宫格/大图+四小图/中心标题+八实物/左右分栏+四局部/杂志拼贴/产品矩阵，禁连续多篇同构图。
- 验收双标准：3 秒看懂 + 10 秒想收藏；只有好看没有想收藏 = 失败。
